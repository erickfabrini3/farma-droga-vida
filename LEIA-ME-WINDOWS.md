# Droga Vida Popular — uso no VS Code

Esta pasta contém o código completo do site da Droga Vida Popular.

## 1. Colocar na pasta correta

Extraia a pasta `Droga vida` para:

`C:\Users\erick\Documents\Droga vida`

## 2. Programas necessários

- Visual Studio Code
- Node.js 22 ou mais recente

## 3. Abrir no VS Code

Dê dois cliques em `ABRIR-NO-VSCODE.bat` ou abra o VS Code e escolha:

`Arquivo > Abrir Pasta > C:\Users\erick\Documents\Droga vida`

## 4. Rodar o site no computador

Na primeira vez, dê dois cliques em `INICIAR-SITE.bat`. Ele instalará os componentes necessários e abrirá o servidor local.

Depois, acesse no navegador:

`http://localhost:5173`

Painel administrativo:

`http://localhost:5173/admin`

Para encerrar o servidor, volte à janela preta e pressione `Ctrl + C`.

## Observações importantes

- O site publicado continuará funcionando normalmente.
- A cópia local possui um banco de testes separado; mudanças feitas localmente não alteram automaticamente o site público.
- As senhas e os dados do banco publicado não foram colocados neste arquivo por segurança.
- Para enviar mudanças da cópia local ao site público, será necessário publicar uma nova versão.
